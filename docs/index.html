How it works

The n-gram model counts trigrams: for a context it has seen it returns the empirical distribution; for an unseen context it falls back to a uniform 1/V guess.

The neural LM (Bengio 2003 style) learns a 2-D embedding for every word. Because alice and bob behave similarly in training they end up close in embedding space — so the model can generalise to contexts like (alice, banana) that counting never saw.
